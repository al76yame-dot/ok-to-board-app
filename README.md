# OK to Board — اليامي

تطبيق PWA لإصدار وثائق **تأكيد صحة السفر (OK to Board)** مع رمز QR، يعمل على الجوال والكمبيوتر ويمكن تثبيته كتطبيق مستقل.

## المميزات

- 📄 توليد وثيقة OK to Board بتنسيق رسمي (عربي + English)
- 🔳 رمز QR تلقائي يحتوي بيانات التحقق
- 📲 PWA قابل للتثبيت على Android / iOS / Windows / Mac
- 🌐 يعمل أوفلاين بعد أول فتح (Service Worker)
- 🖨️ طباعة A4 / حفظ PDF مباشرة من المتصفح

## التشغيل المحلي

افتح `index.html` في المتصفح، أو شغّل سيرفر بسيط:

```bash
npx serve .
```

## النشر

## التثبيت كتطبيق

- **Android/Chrome/Edge:** اضغط زر "📲 تثبيت كتطبيق"
- **iPhone/Safari:** مشاركة → إضافة إلى الشاشة الرئيسية
- **Windows/Mac:** قائمة المتصفح → تثبيت التطبيق
